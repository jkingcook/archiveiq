API Key Required

LetterVault Pro requires an Anthropic API key to process archival items with Claude AI.

To set it up:

  1. Open the Secrets panel in Replit (lock icon in the sidebar)
  2. Add a new secret with key: ANTHROPIC_API_KEY
  3. Paste your Anthropic API key as the value
  4. Restart the application
