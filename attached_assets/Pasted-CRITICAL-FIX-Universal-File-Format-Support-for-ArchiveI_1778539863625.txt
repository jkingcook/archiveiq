===================================================
STEP 2 — BUILD A UNIVERSAL FILE CONVERTER
===================================================
Create a new file: src/utils/universalConverter.ts

This module accepts ANY uploaded file and returns either:
  - A base64 image (for Claude vision processing)
  - Extracted text (for text-based processing)
  - Both where possible

Handle ALL of these input types:

IMAGES (send directly to Claude vision):
  .jpg .jpeg .png .webp .tiff .tif .bmp .gif .heic .heif .avif
  → Convert any non-standard format to PNG via sharp
  → Return base64 + media_type: image/png

SVG:
  .svg
  → Convert to PNG via svg2img or sharp
  → Return base64 + media_type: image/png

PDF:
  .pdf
  → First attempt: extract text with pdf-parse
  → If text extracted successfully AND length > 100 chars:
       return extracted text directly (text-based PDF)
  → If text is empty or too short (scanned PDF):
       use poppler/pdftoppm to render EACH PAGE as PNG
       return array of base64 images, one per page
  → Process ALL pages, not just page 1

MICROSOFT OFFICE:
  .docx → extract text with mammoth
  .doc  → convert via libreoffice then extract
  .xlsx .xls → extract all cell data with xlsx library
  .pptx .ppt → extract slide text via libreoffice + text extraction
  → Return extracted text for Claude to process

OPEN DOCUMENT:
  .odt .ods .odp → convert via libreoffice → extract text

TEXT FILES:
  .txt .md .rtf .csv .tsv .json .xml .html
  → Read as plain text
  → Return text directly

IMAGES IN ARCHIVES:
  .zip .tar .gz
  → Extract contents
  → Process each file inside using the same universal converter
  → Return array of results

EMAIL FILES:
  .eml .msg
  → Extract body text + any attachments
  → Process attachments through universal converter

UNKNOWN TYPES:
  → Detect type by magic bytes using file-type library
  → Apply best-match conversion strategy above
  → If nothing works: attempt raw text read
  → Never return an error to the user — always return 
    SOMETHING for Claude to attempt to process
